# Second-order anti-slop review

Second-order slop is not a single CSS property. It is the loss of intention
that appears when otherwise valid design moves are stacked as a recognizable
template.

Review these combinations contextually:

- Beige editorial page + oversized serif/near-black heading + one italic accent
  word + thin rules, when the page is a technical utility rather than an
  editorial reading surface.
- Dark terminal palette + monospace for body, navigation, labels, and numbers,
  when code is not the user's primary reading task.
- Swiss/grid composition + arbitrary 01/02/03 markers + uppercase labels,
  when there is no sequence or reference index.
- Neobrutalist thick borders + oversized numerals + loud accent colors, when the
  treatment does not clarify state or action.
- Acid-green/orange accent colors + glow + status dots, when no product state or
  brand rationale requires them.
- Anti-slop minimalism + repeated borderless panels, identical alignment, and
  generic copy, when the result is merely another template.

These are WARNING review prompts, not universal prohibitions. Establish the
product task first, identify what the combination communicates, and document an
exception when it is deliberate. A detector cannot determine intention; the
human review must inspect the rendered result.
