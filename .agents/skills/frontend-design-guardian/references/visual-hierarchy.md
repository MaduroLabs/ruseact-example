# Visual hierarchy and composition

Hierarchy should make the next useful decision obvious. It comes from semantic
structure, scale, spacing, alignment, contrast, grouping, and content order—not
from applying the same emphasis everywhere.

Review:

- Is there one clear page or surface purpose?
- Does the first viewport expose the useful task rather than only a slogan?
- Does heading size and weight reflect content importance?
- Does spacing group related items and separate unrelated items?
- Are cards, borders, radii, shadows, badges, and icons doing a specific job?
- Are metrics real and sourced, or decorative instrumentation?
- Does mobile preserve order, readable measure, focus, and access to controls?
- Does the composition still make sense when eyebrow text, numbers, and
  decorative containers are removed?

## Second-order check

An individual serif heading, dark terminal palette, numbered section, rounded
card, or uppercase label is not inherently bad. It becomes a warning when a
combination is applied mechanically, repeated without information gain, or
used to make a generic template appear authored. See
second-order-slop.md.
